### :robot: AI agents for education ([Falken's Lab](https://github.com/falkenslab))

- **[miyagi](https://github.com/falkenslab/miyagi).** AI assistant for teachers: it grades with your rubric, answers the forum, builds topics and quizzes and tells you how the class is going, right in your Moodle course.
- **[moodle-mcp](https://github.com/falkenslab/moodle-mcp).** MCP server for agents to work in Moodle.
- **[moodle-driver](https://github.com/falkenslab/moodle-driver).** Node.js library and CLI for full control of Moodle as any user, with no web services, tokens or admin.
- **[agent-kit](https://github.com/falkenslab/agent-kit).** A foundation for building AI agents on top of the Claude Agent SDK.
- **[pseudonym](https://github.com/falkenslab/pseudonym).** A pseudonymization library for AI tools.
